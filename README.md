## Preferences DataStore

Location: composeApp/src/commonMain/kotlin/com/example/cmpexploreexplainpreserve/dataStorePref

Jetpack DataStore (Preferences) stores data in a file internal to your app. 
The exact location depends on the platform:
- preferences_pb = Protocol Buffer-encoded file.
- This location is not accessible to users or other apps (except root).
  
Documentation:
  https://developer.android.com/topic/libraries/architecture/datastore#preferences-datastore
  https://developer.android.com/kotlin/multiplatform/datastore
